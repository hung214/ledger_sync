## 1. 這是什麼

LedgerSync 是**本地優先記帳 App**：資料存在**你自己的裝置**（不上傳任何伺服器）。
要跨裝置/備份時，你有兩條路：**備份檔**（一個檔案，免帳號）或 **Google Drive 雲端備份**
（需一次性的 Google 設定，見 §6）。

## 2. 安裝

### 2.1 iPhone／iPad（PWA——免簽章、免付費、永久有效）

1. 用 **Safari**（一定要 Safari）開啟：`https://hung214.github.io/ledger_sync/`
2. 點底部「分享」（□↑）→ 選「**加入主畫面**」→ 名稱確認 →「加入」
3. 主畫面出現 **LedgerSync 圖示** → 點開即是 App（全螢幕、無網址列）
4. **離線也能用**（第一次開啟後快取完成）

> ⚠ iPhone 必須用 **Safari** 安裝（Chrome on iOS 不支援加到主畫面）。

### 2.2 電腦（macOS／Windows）

1. 取得安裝檔（macOS＝DMG；Windows＝exe 安裝檔）——由 PM 提供或 GitHub Release 下載
2. macOS：拖進「應用程式」→ 首次開啟右鍵→「打開」（未簽章提示）；Windows：雙擊安裝
3. 更新＝重新下載安裝新版

### 2.3 Android

1. 下載 APK（PM 提供或 GitHub Release）→ 點開 → 允許「安裝未知應用」→ 完成
2. 更新＝重新安裝新版 APK（資料不受影響）

### 2.4 PWA 更新方式（**自動**；2026-11-17 起）

- **有新版會自動更新**：開啟 App 時背景檢查（另有每小時／回到前景時檢查）→
  偵測到新版 → 自動下載 → **畫面自動重載一次**即為新版（不需手動重新整理）
- 目前版本可在 **總覽頁尾** 看到（如 `0.5.0-pwa.20261117`）
- 提醒：伺服器快取最長 10 分鐘——剛發佈的新版最慢約 10 分鐘後被偵測到
- 若畫面異常：重新整理一次即可；持續異常再回報

## 3. 開始記帳

- **快記**：手機＝右下 **＋**；桌面＝右上「快速記帳」（或 ⌘N）→ 金額 → 分類 → 儲存
- **掃描發票**：手機＝右下**掃描圖示**（快記上方）；桌面＝工具列「掃描」（或 ⌘⇧S）
  → 選發票照片 → 自動解析金額/日期 → 確認入帳
- **明細／統計**：底部（桌面側欄）切換；統計三卡可點選切換指標

## 4. 資料安全（最重要的一節）

資料存在**本裝置**，因此：

> ⚠ **定期備份**。尤其 iPhone 的 PWA：若你刪除主畫面圖示、或清除 Safari 網站資料，
> **本地資料會一起消失**。備份後就安全。

### 4.1 備份到檔案（免帳號，推薦每個人都做）

1. 設定 → **資料管理** → 「備份與還原」→ **備份到檔案**
2. 選存檔位置（iPhone=存到「檔案」App／電腦=選資料夾）→ 產生 `ledger_backup_日期.db`
3. 這個檔案＝你全部的帳本（交易/帳戶/分類/預算/設定）

### 4.2 從檔案還原（換機、分享給朋友、救回資料）

1. 新裝置先安裝 App（§2）
2. 設定 → 資料管理 → 備份與還原 → **從檔案還原** → 選備份檔 → **二次確認**
3. 完成（覆蓋目前資料——舊資料會被備份檔取代）

### 4.3 雲端備份（Google Drive；跨裝置自動同步）

- 需先完成 **§6 的 Google 設定**（PM 一次設定；朋友首次登入即可）
- 之後：設定 → 雲端備份 → 登入 Google → 自動備份＋跨裝置同步＋衝突檢視
- 好處：自動、多裝置；備份檔方式的好處：零設定、完全自主——兩者可並用

## 5. 從其他 App 匯入（CSV）

### 5.1 先從原記帳 App 匯出 CSV

1. 開原記帳 App → 找 **匯出**（通常在設定／工具選單；多數 App 支援 CSV）
2. 選 **CSV**（或 Excel 後另存 CSV）→ 匯出全部歷史
3. 把檔案傳到要匯入的裝置（AirDrop／雲端硬碟／電腦）

### 5.2 匯入 LedgerSync

1. 設定 → 資料管理 → **從其他 App 匯入** → 選擇 CSV 檔案
2. **預覽**：可匯入筆數／期間／支出收入合計／轉帳筆數／**將自動建立的帳戶與分類**／
   重複（自動跳過）／錯誤列（略過）／非 TWD（略過）
3. 點「開始匯入」→ 報告（新增 N 筆…）
4. **反悔？** 報告頁可「**取消本批匯入**」——整批退掉（其他裝置也會同步刪除）
5. **重複匯入安全**：同一份檔案再匯一次＝全部跳過，不會重複記帳
   （去重規則＝日期＋金額＋備註＋帳戶）

## 6. Google 雲端備份設定（PM 一次性設定；朋友只需登入）

### 6.1 PM：建立 Google 憑證（約 10 分鐘，不用付費）

| # | 動作 | 在哪裡 |
|---|---|---|
| 1 | 開 console.cloud.google.com → 建立/選擇專案（如 `ledgersync`） | 首頁 |
| 2 | 搜尋「Google Drive API」→ **啟用** | API 和服務 → 程式庫 |
| 3 | **OAuth 同意畫面**：外部 → App 名稱 `LedgerSync`＋你的 email → 儲存；**測試使用者**加入你與朋友的 Gmail | API 和服務 → OAuth 同意畫面 |
| 4 | 憑證 → 建立憑證 → OAuth 用戶端 ID → **網頁應用程式**（PWA 用）：JavaScript 來源加 `https://hung214.github.io` 與 `http://localhost:8899` → 複製 **Client ID** | 憑證 |
| 5 | 再建 **桌面應用程式**（macOS/Windows 用）→ 複製 **Client ID＋Client Secret** | 憑證 |
| 6 | 把三個值交給開發者：**Web Client ID／Desktop Client ID／Desktop Secret** | — |

> 安全：資料存使用者**自己的 Drive** 隱藏資料夾（計各自 15GB 額度）；
> Secret 只進本機建置參數、不進 git。測試使用者名單外的帳號無法登入（加進去即可）。

### 6.2 使用者：登入雲端備份（PM 設定完成後）

1. 設定 → **雲端備份** → 「登入 Google 並啟用雲端備份」
2. Google 登入頁 → 選帳號 → 允許 → 回到 App
3. 之後自動備份＋跨裝置同步；PWA 版行為相同

## 7. 常見問題

| 問題 | 答案 |
|---|---|
| 資料存在哪？會上傳嗎？ | 本裝置本地。不上傳（除非你開啟雲端備份——存你自己的 Drive） |
| 刪掉 PWA 圖示資料會不見嗎？ | **會**（連瀏覽器網站資料一起清）→ 先「備份到檔案」或開啟雲端備份 |
| 換手機怎麼搬資料？ | ①備份檔：舊機備份→新機「從檔案還原」②雲端：新機登入同一 Google 帳號 |
| 朋友 iPhone 怎麼裝？ | §2.1（Safari 開網址→加入主畫面）；無需帳號、無需 App Store |
| 匯入後發現不對？ | 匯入報告頁「取消本批匯入」→ 整批退掉 |
| PWA 顯示舊版？ | 重新整理兩次；手機刪圖示重裝（§2.4） |
| 掃描怎麼用？ | 手機＝掃描 FAB；桌面＝工具列「掃描」或 ⌘⇧S → 選發票照片 |
| 多個裝置資料會打架嗎？ | 開啟雲端同步後有合併規則＋衝突檢視（雲端備份頁） |
