# 驗收規格：F12 — 從其他 App 匯入（AndroMoney）

| 項目 | 內容 |
|---|---|
| 對應需求 | SPEC FR-O5（§5.10）；SDD §5.6b |
| 里程碑 / 優先級 | 匯入批 / P1 |
| 所需環境 | ①乾淨帳本 ②已連結雲端（驗證匯入前備份） ③AndroMoney 匯出之 CSV |

## 1. 驗收情境（AC）

| # | 情境 | 步驟 | 預期 |
|---|---|---|---|
| F12-S1 | 匯入入口 | 設定→資料管理 | 見「從其他 App 匯入」卡（`import-entry`） |
| F12-S2 | 選檔與預覽 | 點入口→選 AndroMoney CSV | 預覽卡：**可匯入筆數／期間／支出收入合計／轉帳筆數／重複（跳過）／錯誤列（略過）／非 TWD（略過）／將自動建立之帳戶與分類清單** |
| F12-S3 | 匯入落地 | 點「開始匯入」 | 報告＝新增 N 筆（含轉帳 X）／自動建立帳戶 A 個、分類 B 個；明細/統計即時反映；**未知帳戶與分類已自動建立**（子分類掛於主分類） |
| F12-S4 | 重複匯入冪等 | 再次匯入**同一份** CSV | 可匯入 0 筆（全部命中去重）；帳本資料不變 |
| F12-S5 | 去重語意 | 檔內或既有資料中「**同日期＋同金額＋同備註＋同帳戶**」 | 視為重複→跳過；同日同額但備註不同→**不**算重複 |
| F12-S6 | 非 TWD | CSV 含 USD 列 | 該列**略過**並於預覽/報告標示「非 TWD 略過」 |
| F12-S7 | 匯入前自動備份（已連結雲端） | 連結雲端後匯入 | Drive `backups/{ts}.db` 出現本次備份；報告顯示「已先完成雲端備份 ✓」 |
| F12-S8 | 取消本批匯入 | 匯入後報告頁點「取消本批匯入」 | 該批全部交易**軟刪除**（最近刪除可見）＋**墓標 oplog**（其他裝置同步刪除）；重複呼叫冪等 |
| F12-S9 | 錯誤列不擋整批 | CSV 混入壞日期／壞金額列 | 好列照常匯入；壞列計入「錯誤略過」 |
| F12-S10 | Web（PWA） | 於 `https://hung214.github.io/ledger_sync/` 走 S1-S8 | 行為一致（file_selector web；附件/DB 走瀏覽器儲存） |

## 2. 測試現況

- 單元：parser 10（別名/分隔符/日期/金額/類型/錯誤/幣別）＋service 7（預覽/落地/冪等/去重/幣別）。
- Widget：入口存在＋「預覽→匯入→報告→取消本批」（fake file_selector；墓標=2/active=0）。
- **實機驗收**：待 PM 提供 AndroMoney CSV（tasks §6.0 I1）→ 對照真實資料走查 S1-S8。
