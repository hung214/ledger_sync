# LedgerSync v0.5.0 Release Notes（草稿——發版時貼 GitHub Release）

> 定位：本地優先記帳（macOS／Windows／Android／iOS／PWA 五形態；PWA 為朋友主要渠道）。

## Highlights
- 快速記帳 v4（多筆＋Sticky＋常用分類＋復原）／明細（搜尋篩選編輯刪除還原）／統計
- 信用卡全流程：期結帳、部分繳款、逾期徽章、帳單歷史、未來已承諾（分期）、繳款
- 預算警示／定期交易佇列／帳戶與分類管理
- 掃描：發票 QR 解析＋OCR 欄位抽取＋**PWA 即時相機掃描**＋桌面檔案匯入
- CSV 匯入（別名中英、自動建帳戶分類、**去重冪等＋重複可選略過/覆蓋**）／CSV 匯出（major 兩位小數）
- 資料安全：檔案備份還原、桌面每日自動備份、PIN 鎖（Argon2id）、隱私遮蔽
- **資料版本戳**：任何變更全 App 同步刷新
- PWA：offline-first＋自動更新＋版本標章；CI 四平台

## 修復（PM 實測回饋；11/18–19）
- 啟動灰畫面（引導頁 MaterialApp 外）／清空資料沒反應（provider 漏接線）
- 匯出沒有真存檔＋只有單月 → 範圍可選（全部/篩選）＋真存檔（macOS 對話框/web 下載）
- 匯出→匯入來回相容（日期時間別名/轉入帳戶/金額 major）
- 重複匯入沒攔到（去重當日範圍比對）／信用卡應付恆 0（settlement 修復＋資料修復）
- 帳戶刪除連動交易＋孤兒交易一次性修復／macOS 沙盒存檔權限
