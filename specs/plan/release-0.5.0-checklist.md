## A. 快速記帳（核心閉環）
- [ ] 記一筆支出 → Saved 對話框出現、繼續記第二筆（Sticky：帳戶/分類保留）
- [ ] 明細立即出現該筆、總覽/統計數字即時變動（資料版本戳）
- [ ] 復原上一筆 → 明細消失、出現在「最近刪除」
- [ ] 帳戶選單即時反映帳戶管理的新增（不用重啟）

## B. 明細
- [ ] 篩選（帳戶 chips／收支性質／月份切換）
- [ ] 編輯一筆 → 明細與總覽同步更新
- [ ] 匯出 CSV → 選「全部資料」→ 存檔（macOS 對話框／PWA 下載）→ 打開檔案金額是人類可讀（1.00＝1 元）

## C. 匯入（重點：去重）
- [ ] 匯入剛才匯出的 CSV → 預覽顯示「重複：N 筆」→ 預設略過 → 匯入後**0 重複**
- [ ] 再匯一次改商家版的檔案 → 選「覆蓋既有資料」→ 報告顯示「覆蓋 N 筆」
- [ ] 信用卡帳戶的匯入支出 → 信用卡頁「應付」有數字（非 0）
